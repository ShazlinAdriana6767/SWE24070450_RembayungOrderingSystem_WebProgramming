# Rembayung Ordering System

A web-based food ordering system built for the Web Programming course at German-Malaysian Institute (GMI).

## Features
- Login system with role-based access (Admin, Staff, Customer)
- Menu browsing and order cart
- Automatic price calculations
- CRUD operations for menu items and orders

## Tech Stack
- PHP
- HTML
- MySQL (phpMyAdmin)

## How to Run
1. Install XAMPP (or Laragon) and start Apache and MySQL.
2. Copy the project folder into `htdocs` (XAMPP) or `www` (Laragon).
3. Open phpMyAdmin, create a database, and import the `.sql` file from this project.
4. Update the database details in the connection file if needed.
5. Open `http://localhost/rembayung` in your browser.
